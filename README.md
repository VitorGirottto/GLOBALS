# 📦 Estrutura de Dados: Pilha em PHP com Menu Interativo

Este projeto implementa uma **pilha (stack)** em PHP com funcionalidades completas e interativas via terminal. Utiliza a variável superglobal `$GLOBALS` para armazenar os dados da pilha globalmente.

## 🔧 Funcionalidades

- ✅ Adicionar item à pilha
- ✅ Remover item do topo da pilha
- ✅ Imprimir toda a pilha
- ✅ Ver o topo da pilha (sem remover)
- ✅ Ver o tamanho da pilha
- ✅ Esvaziar a pilha
- ✅ Verificar se um item está na pilha
- ✅ Menu interativo para testes via terminal

## 📂 Arquivo

- `pilha.php` – Arquivo principal com a classe `pilha` e o menu interativo
